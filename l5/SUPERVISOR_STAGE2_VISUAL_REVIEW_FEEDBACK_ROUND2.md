## 4. 关于“只允许 GitHub”和“必须肉眼检查 PNG”的边界说明

上一条工作命令确实容易被理解成矛盾：一方面说“只允许操作 GitHub”，另一方面又要求“实际打开 PNG 肉眼检查”。

这里重新定义：

### 允许

- 所有**写入、修改、生成、提交**只能发生在 GitHub 工程中；
- 可以从 GitHub 仓库或 GitHub Actions artifact **只读下载**最终渲染 PNG/JPG/PPTX 到本地临时 sandbox，用于视觉检查；
- 可以使用当前模型自带的图像查看/视觉能力检查这些只读副本；
- 检查结束后，不需要把临时本地文件作为工程源文件使用。

### 禁止

- 禁止在 Canvas、Work、Writing Block 或其他外部编辑器中修改 PPT；
- 禁止使用 image generation 重画课程科学图；
- 禁止在本地临时 sandbox 修改 PPT 后绕过 GitHub 提交；
- 禁止因为 GitHub connector 不能直接预览二进制 PNG 就跳过视觉检查。

如果 connector 不能直接显示仓库图片，正确做法是：

**GitHub 生成 → GitHub artifact/仓库文件 → 只读下载到 sandbox → 用视觉能力检查 → 所有修正继续回 GitHub 完成。**

这不违反“工程操作只在 GitHub”的要求。
